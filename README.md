# kick-schedule

KNOCK OUTクロスポイント吉祥寺の時間割のうち、キック系クラスだけを iPhone のカレンダーで購読するためのファイル置き場です。

| ファイル | 内容 |
| --- | --- |
| `schedule.json` | ジム公式ページの時間割画像から読み取ったキック系クラス（版ごとに管理） |
| `build_ics.py` | `schedule.json` から `kick.ics` を生成するスクリプト（Python 標準ライブラリのみ） |
| `kick.ics` | iPhone の「照会するカレンダー」に登録するファイル |

## 対象クラス
- 含む：キック入門／超入門／中級／中上級／キックALL／キック&マス入門／マス入門、朝フリーキック／フリーキック／ミット&マススパーリング、フィジカル
- 除く：柔術、グラップリング、MMA、レスリング、キッズ、レディース、TAE BO、体験クラス、FREE枠、選手練習系

## 更新の流れ
1. 毎月25日と1日に、ジム公式ページの時間割（見出しの版名と画像URL）が変わっていないか確認する
2. 変わっていれば、新しい画像を読み取り `schedule.json` に新しい版を追加する（`valid_from` に適用開始日）
3. `python3 build_ics.py` で `kick.ics` を再生成してコミットする
   - 旧版の予定は新しい版の開始日前日で打ち切られ、過去分はカレンダーに残る
